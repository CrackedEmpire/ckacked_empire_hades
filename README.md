# Cracked Empire

Сайт художника Cracked Empire (Hades): портфолио, комикс Almost Humans и форма заказа.

Стек: React, TanStack Start, Tailwind.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Сайт откроется на http://127.0.0.1:8080

## Что внутри

- `src/` — страницы и тексты (английский и русский)
- `public/works/` — работы и лист обложек комикса
- `migrations/` — таблицы, если подключить базу

Цены и тексты лежат в `src/data/studio.ts`.
